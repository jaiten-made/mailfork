## Scope

The admin page (`public/index.html`, `style.css`, `app.js`). Mode: Operate.

## Audience and job

The Owner, usually on a phone, partway through another site's signup: give a Label, get a working Profile Address, copy it. Secondary: rename, Retire with typed confirmation, see Retired Profiles, fix a failed push to Cloudflare. Main job confirmed 2026-10-25: fast new address. Feels wrong: SaaS dashboard, playful novelty, too sparse to read state, hacker cliché.

## Constraints

Static HTML, CSS and vanilla JS on the JSON API; CSP `default-src 'self'`, so no inline styles or scripts and no external fonts. Light and dark.
